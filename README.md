# NEFER Jewelry — Landing Page

## Project Overview

NEFER is a fictional jewelry brand landing page inspired by timeless elegance, Egyptian heritage, and fine craftsmanship.

The website presents the brand, showcases its jewelry collections, displays customer testimonials, and provides contact and newsletter sections.

## Features

* Responsive landing page for desktop, tablet, and mobile.
* Navigation menu with a mobile hamburger toggle.
* Hero section with a call-to-action button.
* Jewelry collection cards.
* Customer testimonials.
* Contact form and newsletter section.
* Footer with contact information and social media links.
* Smooth scrolling, hover effects, and basic animations.
* Accessibility considerations, including descriptive image text and visible keyboard focus indicators.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

* `index.html` — page structure and content.
* `style.css` — styling, responsive layouts, and animations.
* `script.js` — mobile navigation behavior.
* `images/` — website images.

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Ensure the `images` folder remains in the project directory.
